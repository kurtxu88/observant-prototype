One door

Your users' feedback and the research engine — in the same MCP.

Connect once. Observant gives your editor agent two things: the raw feedback your users have already given you, and the engine that runs new studies and synthesizes it. No dashboard to open, no export to wrangle.

Observant data · live

Pull your feedback

What your users actually said — read it where you build.

  • observant_recent_feedbackIn-product snippet feedback — thumbs, exit reasons, short notes, CSAT.
  • observant_conversationsOff-product 1:1 threads (email/Telegram) with every turn, per named user.
  • observant_insightsSynthesized Signals — Issues, Insights, Opportunities, grounded in quotes.
Codified engine · bridged

Run the research

Orchestrate new studies over that same feedback, from the editor.

  • codified_run_studyKick off a round — churn, drop-off, PMF, launch feedback. Observant recruits + runs the 1:1s.
  • codified_query_insightsSearch synthesized insights by feature or topic across studies.
  • codified_search_transcriptsFull-text search every interview transcript for what users said.
Connect

One command to wire it into your editor.

Add the MCP server over HTTP — Claude Code, Cursor, or Claude Desktop. No dashboard, no setup call.

$ claude mcp add --transport http observant https://www.observanthq.com/api/mcp

Cursor & Claude Desktop: point an HTTP MCP server at the same URL. Want studies too? Add the engine alongside it:

$ claude mcp add codified -- npx -y @usercodified/mcp
